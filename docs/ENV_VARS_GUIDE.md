# Environment Variables Guide

This guide explains every environment variable used in the Grandma Chen Care Coordinator app in plain language.

| Variable Name | What it's for (one plain sentence, no jargon) | Where its value comes from | Used by (local app / SageMaker / CockroachDB / Render / MCP — whichever applies) | Required in Render dashboard? (yes/no) | Required locally only? (yes/no) |
| --- | --- | --- | --- | --- | --- |
| `AWS_ACCESS_KEY_ID` | Authenticates your app to access AWS cloud services securely. | AWS IAM Console under Security Credentials. | SageMaker, Local App, Render | Yes | No |
| `AWS_SECRET_ACCESS_KEY` | Acts as the password for your AWS access key to sign cloud requests. | AWS IAM Console when creating an Access Key. | SageMaker, Local App, Render | Yes | No |
| `AWS_REGION` | Specifies the geographical AWS data center region holding your AI embedding model. | Set to `ap-south-1` (Mumbai) or your chosen AWS region. | SageMaker, Local App, Render | Yes | No |
| `COCKROACH_CLOUD_URL` | Connects your application to your live CockroachDB Cloud database. | CockroachDB Cloud Dashboard under "Connect". | CockroachDB, Local App, Render | Yes | No |
| `COCKROACH_URL` | Connects your application to an offline local Docker database during local development. | Docker local container connection string (`postgresql://root@localhost:26257/agent_memory?sslmode=disable`). | CockroachDB, Local App | No | Yes |
| `DB_MODE` | Determines whether the app connects to CockroachDB Cloud, Cloud MCP, or local Docker. | Set to `cloud` for production, `cloud-mcp` for MCP testing, or `local` for Docker. | CockroachDB, Local App, Render | Yes | No |
| `EMBEDDING_MODE` | Chooses whether vector embeddings are generated by AWS SageMaker or a local Python package. | Set to `sagemaker` for AWS production or `local` for offline testing. | SageMaker, Local App, Render | Yes | No |
| `SAGEMAKER_ROLE_ARN` | Gives AWS SageMaker permission to access required AWS resources during endpoint deployment. | AWS IAM Console under Roles. | SageMaker | No | Yes |
| `SAGEMAKER_ENDPOINT_NAME` | Identifies the specific deployed AWS SageMaker model endpoint used for generating vector embeddings. | AWS SageMaker Console or script output (e.g. `caregiver-bge-embeddings`). | SageMaker, Local App, Render | Yes | No |
| `COCKROACHDB_MCP_API_KEY` | Authenticates your app when querying CockroachDB through the Model Context Protocol (MCP) server. | CockroachDB Cloud Dashboard under Service Accounts -> API Keys. | MCP, Local App | No | Yes |
| `ANTHROPIC_API_KEY` | Authenticates requests to Anthropic Claude for synthesizing human-like responses. | Anthropic Console under API Keys. | Local App, Render | Yes | No |
| `ANTHROPIC_MODEL` | Specifies which Claude AI model version generates caregiver answers. | Set to `claude-haiku-4-5-20251001` or desired Claude model name. | Local App, Render | Yes | No |
| `ACTIVE_CONVERSATION_ID` | Specifies the active dataset conversation UUID loaded by default when the web interface boots. | CockroachDB conversation ID string (e.g. `327dff0c-19f4-49db-b1c0-01aa51fc7594`). | Local App, Render | Yes | No |
